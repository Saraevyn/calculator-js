# Calculadora JavaScript

Uma calculadora funcional e responsiva desenvolvida com foco em semântica, acessibilidade e design intuitivo. Este projeto foi criado para aplicar conhecimentos em lógica de programação.



## 🚀 Funcionalidades

O projeto oferece uma interface limpa para realizar as operações matemáticas fundamentais:

* **Soma:** Adição de valores.
* **Subtração:** Diferença entre valores.
* **Multiplicação:** Produto de valores.
* **Divisão:** Cálculo de quocientes.
* **Design Adaptável:** Interface otimizada para diferentes dispositivos.

## 🛠️ Tecnologias Utilizadas

Para a construção deste projeto, foram utilizadas as seguintes tecnologias:

* **HTML5:** Estrutura baseada em elementos semânticos.
* **CSS3:** Estilização moderna com foco em experiência do usuário.
* **JavaScript:** Lógica de funcionamento e interatividade.
